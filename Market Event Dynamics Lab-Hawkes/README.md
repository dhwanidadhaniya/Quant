# Market Event Dynamics Lab

Empirical laboratory for Hawkes processes in market microstructure.

## Research question

To what extent can the clustering and interaction of financial market events be explained by self-exciting point processes?

This is not a trading bot and not a price-prediction demo.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

## Stack

Client-side TypeScript: multivariate exponential Hawkes, Ogata thinning, MLE, residual analysis, Monte Carlo. No backend.
